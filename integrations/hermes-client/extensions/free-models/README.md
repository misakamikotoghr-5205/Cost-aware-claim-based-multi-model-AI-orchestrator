# Free models native extension

This independent install package contains the Python discovery adapters,
authenticated REST backend and native Desktop SDK page. It requires
`orchestrator-core`; it is not preinstalled in that package.

An explicit refresh reads the public OpenRouter catalog and the configured
loopback Ollama inventory. No model inference, subscription login, model pull,
paid API call or background schedule is performed. Token Scout/FMM/Ollama exports
can also be imported with source timestamps. Current zero-price evidence, TTL,
provider availability and account quota remain distinct.

Install and enable it through native extension management. Read
[native extensions](../../../../docs/native-extensions.md) for billing evidence,
expiration, native route configuration and REST details.
