# MISAKA AGENT 额度总览

点击客户端侧栏 **Dashboard**，在原生界面查看当前本机配置中的账号用量、
共享云端工作配额和本机节点状态。页面使用 Hermes 的原生插件 SDK，和聊天、
账号登录、模型设置处于同一个桌面客户端。

Dashboard 随 `orchestrator-core` 提供，不需要安装判断模型、免费模型或智能指针。
首次安装核心包后，在原生插件页启用 **Agent**，等待当前任务完成，重启对应本机
代理，再重新连接。仅启用 Desktop 页面不会向已经运行的代理追加后端接口。
接口尚未加载时，页面会显示这一步操作提示，不会自动终止任务或重启代理。

## 读取与刷新

打开页面只读取本机已有记录。点击 **读取最新额度** 才请求后端刷新实际用量，
页面随后读取本次刷新的状态和结果。未登录、服务未公开用量、记录过期或读取失败
都有明确的原因；未知额度不会显示成零余额或零使用率。

每个账号分别显示服务商、用量窗口、剩余额度、来源、采集时间和下次重置时间。
仅当有效记录提供了同一窗口的用量与上限时才绘制进度条：

- 订阅百分比是服务返回的窗口用量比例，不换算成 Token 数。
- USD 和 CNY 余额保持原始货币，不进行汇率换算。
- 请求次数、Token、积分和其他计量单位分别展示，不跨单位汇总。
- 云端工作配额来自私网调度账本，单独显示已占用和可调度数量，不能当作服务商余额。

支持范围以实际后端返回结果为准；拥有 API 密钥或订阅不等于服务提供了可查询的
额度接口。原生账号尚未配置时，点击 **账号与模型设置** 或 **打开原生账号设置**，
客户端先激活页面选定的本机配置，再强制将原生设置的作用范围绑定到该配置。
即使当前 profile 名称没有变化，之前留下的其他设置作用范围也会被替换。
旧客户端缺少这个能力时会提示升级，不会打开一个无法确认账号范围的设置页面。
登录与密钥管理继续使用
原生流程，Dashboard 不创建另一套登录入口。

## 本机配置范围

页面顶部的 **本机配置（profile）** 决定本次读取的账号范围。切换后会清除旧页面
数据，迟到的旧请求不能覆盖新配置。聊天当前连接到云端时，Dashboard 的读取、
刷新和导入请求仍然只访问所选本机配置。

**共享云端额度** 是该本机配置显式连接的私网账本快照；**本机节点** 显示对应
代理的执行位置、操作系统与任务接收状态。没有配置云端时，可以直接进入原生的
云端与本地协同页面配置，普通本机聊天不需要启用云端。

## 导入已有用量快照

展开 **导入已有用量快照**，选择标准快照或对应服务商格式，再明确选择本机 JSON
文件。原始服务商快照必须填写文件内容的实际采集时间；页面不会默认使用导入时刻。
导入保留数据原有的有效期和重置时间，过期快照不会因为重新导入而变成新记录。

页面不会自行扫描本机账号文件，也不会因为打开 Dashboard 而导入文件或刷新远程
用量。不同本机配置的数据保持各自范围。
